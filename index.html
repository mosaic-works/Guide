Các bước cài đặt

Hướng dẫn thiết lập môi trường, công cụ và khởi chạy dự án từ đầu.

Phần 1

Môi trường code & Công cụ cơ bản

Tối ưu giao diện Windows, tải bộ cài đặt và thiết lập VS Code.

1. Cấu hình Windows tránh nhảy tab Microsoft Edge khi Alt + Tab

Vào Settings → System → Multitasking → Tại mục Alt + Tab chọn: Don't show tabs.

Clone mã nguồn dự án từ GitHub Tải toàn bộ source code dự án về máy tính qua Git:
Mở GitHub
git clone https://github.com/mosaic-works/Guide.git
2. Cài đặt môi trường & phần mềm lập trình
  1. VS Code: Trình soạn thảo mã nguồn chính + Antigravity IDE.
  2. Git Bash: Công cụ điều khiển dòng lệnh Git trên Windows.
  3. Extensions cho VS Code: Cài đặt 3 tiện ích mở rộng bắt buộc: Code Runner, HTML CSS Support, Live Server.
Phần 2

Cài đặt Node.js, npm & Git

Cài đặt qua dòng lệnh winget hoặc tải trực tiếp từ trang chính thức.

Tải bộ cài thủ công từ website chính thức

Node.js: nodejs.org/en/download  ·  Git: git-scm.com/install/windows

Cài đặt Node.js LTS (qua Winget trong PowerShell)
winget install --id OpenJS.NodeJS.LTS -e --source winget --accept-package-agreements --accept-source-agreements
Cài đặt Git (qua Winget trong PowerShell)
winget install --id Git.Git -e --source winget --accept-package-agreements --accept-source-agreements
Bật quyền thực thi Script trên PowerShell (RemoteSigned)
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Kiểm tra phiên bản npm sau khi cài
npm -v
Phần 3

Cấu hình tài khoản GitHub trên máy

Thiết lập thông tin tác giả commit và đăng nhập tài khoản máy tính.

1. Cấu hình thông tin tác giả commit
git config --global user.name "thanhthong99999"
git config --global user.email "thanhthongdev.1999@gmail.com"
2. Kiểm tra lại thông tin cấu hình
git config --global --list
3. Đăng nhập GitHub trên máy tính (Git Credential Manager)

Kiểm tra phiên bản Git Credential Manager:

git credential-manager --version

Đăng nhập vào tài khoản GitHub:

git credential-manager github login
Phần 4

Khởi chạy dự án (Khi tải/clone từ GitHub về)

Các lệnh cài đặt dependencies, build và khởi chạy dev server.

Trình tự chạy dự án lần đầu
  1. Bước 1: Cài đặt sạch các gói thư viện từ file lock
    npm ci
  2. Bước 2: Cài đặt hoặc bổ sung phụ thuộc
    npm install
  3. Bước 3: Biên dịch build thử nghiệm
    npm run build
  4. Bước 4: Chạy máy chủ phát triển cục bộ
    npm run dev
Lệnh kiểm tra khi gặp sự cố hoặc lỗi package

Kiểm tra gói Vite trong dự án:

npm ls vite

Kiểm tra nội dung file cấu hình package.json:

Get-Content package.json
